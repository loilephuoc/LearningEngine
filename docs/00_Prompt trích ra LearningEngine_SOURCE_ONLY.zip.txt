# Chuẩn hóa baseline source của Learning Engine 2.0

Mình sẽ đính kèm:

* LearningEngine.zip

Đây là snapshot mới nhất của project.

========================
MỤC TIÊU
========

Từ LearningEngine.zip, hãy tạo ra một baseline source sạch chỉ chứa source cần thiết.

Tên file kết quả:

**LearningEngine_SOURCE_ONLY.zip**

Đây sẽ là baseline chính thức cho tất cả các cuộc trò chuyện sau.

========================
YÊU CẦU
=======

Không được phân tích hay sinh code ngay.

Trước tiên hãy chuẩn hóa source.

========================
CÁC BƯỚC PHẢI THỰC HIỆN
=======================

1. Giải nén LearningEngine.zip.

2. Đọc toàn bộ cấu trúc project.

3. Xác định module source thực tế.

4. Loại bỏ toàn bộ những thứ không cần thiết.

Bao gồm nhưng không giới hạn:

* .git/
* .github/
* .gradle/
* .idea/
* .kotlin/
* build/
* out/
* bin/
* target/
* cache/
* reports/
* test-results/
* logs/
* tmp/
* *.iml
* *.log
* *.class
* .DS_Store
* Thumbs.db

Loại bỏ:

* toàn bộ file sinh ra khi build
* toàn bộ cache
* toàn bộ artifact
* source duplicate
* thư mục duplicate (ví dụ src/src nếu có)
* file tạm
* file IDE

Giữ nguyên:

* src/
* desktop/src/
* android/src/ (nếu có)
* ios/ (nếu có)
* shared/ (nếu có)
* mọi module source thật sự
* resources
* Gradle
* docs
* README
* LICENSE
* settings.gradle*
* build.gradle*
* gradle.properties
* gradle wrapper

Không được tự ý xóa:

* source Kotlin
* source Java
* resource
* Gradle
* docs

========================
KIỂM TRA
========

Sau khi lọc xong:

1. Kiểm tra lại toàn bộ cấu trúc.

2. Đảm bảo:

* không còn duplicate source
* không còn cache
* không còn build artifact
* không còn file IDE
* không mất source

========================
ĐÓNG GÓI
========

Đóng gói thành:

**LearningEngine_SOURCE_ONLY.zip**

========================
PHẢN HỒI
========

Không cần giải thích code.

Không cần sinh code.

để mình tải về.
