## Allocation and finite-palette note

Known catalog identities are fixed in code. Unknown canonical text is encoded with UTF-8 and
SHA-256; its stable identity includes a digest prefix and the canonical label. A 1,048,576-slot
visual space derives theme-safe hue/tone/border presentation. The active registry probes on an
occupied initial slot without changing prior in-memory assignments.

This is a finite visual palette: the implementation guarantees unique semantic keys for active
canonical POS and distinct keys for the current inventory, but it does not claim a globally
unique visible hue for every possible future string. Badge text and border remain mandatory, so
color is never the only information channel.
